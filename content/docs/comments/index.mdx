# コメント

コメントとは、**プログラム内に書けるメモ**のことです。実行結果には影響しません。

HTML、CSS、JavaScriptでは、コメントの書き方が異なります。

## コメントとは

- コードに説明を加えるためのもの
- ブラウザには表示されない
- コードの理解を助ける
- 一時的にコードを無効化する場合にも使用

## HTMLでのコメントの書き方

```html
<!-- コメントの内容 -->
```

### コメントの例

```html
<!-- これは見出しです -->
<h1>タイトル</h1>

<!-- 
  複数行のコメントも
  このように書けます
-->
<p>本文</p>

<!-- 一時的に無効化
<img src="image.jpg" alt="画像">
-->
```

## CSSコメント

CSSでコメントを書く場合は、`/* */` で囲みます：

```css
/* これはコメントです */
h1 {
  color: red; /* 見出しを赤色にする */
}

/*
複数行の
コメントも
書けます
*/
p {
  color: blue;
}
```

## JavaScriptコメント

JavaScriptでは、1行コメントと複数行コメントがあります。

```js
// 1行コメント（// 以降の行がコメントになる）

/*
  複数行にまたがるコメント
  ここも無視される
*/
```

```js
// 変数 greeting を宣言し、あいさつ文を入れる
let greeting = "こんにちは";

console.log(greeting); // 出力: こんにちは
```

## コメントアウト

一時的に処理を無効にしたいときに、その行をコメントにすることを**コメントアウト**といいます。

```js
let value = "テスト";
// console.log(value); ← この行は実行されない
console.log("別の処理"); // 出力: 別の処理
```

## 覚えておくこと

- コメントとは、プログラム内に書けるメモのことです。
- コメントは実行結果には影響しません。
- コメントアウトとは、一時的に処理を無効にしたいときに、その行をコメントにすることです。
- HTML、CSS、JavaScriptでは、コメントの書き方が異なります。
