# Code of Conduct

## Our Pledge

We pledge to make participation in this project respectful and harassment-free for everyone.

## Expected Behavior

- Use welcoming and inclusive language.
- Respect different viewpoints and experiences.
- Give and accept constructive feedback gracefully.
- Focus on what is best for learners and maintainers.

## Unacceptable Behavior

- Harassment, intimidation, or discriminatory language.
- Personal attacks or sustained disruption.
- Publishing private information without permission.

## Enforcement

Maintainers may remove, edit, or reject comments, commits, issues, and pull requests that do not align with this Code of Conduct.
